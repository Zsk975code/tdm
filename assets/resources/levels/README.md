# 地图文件夹（assets/resources/levels）

把 `.json` 地图文件丢进这个文件夹，游戏会**自动扫描并加载**，选关界面立刻出现对应关卡。
不需要改任何代码，不需要登记文件名。

---

## 3 步上手

1. 复制 `_template.json`，重命名为 `01_我的地图.json`
2. 改里面的 `path`（怪物路线）和 `towerSpots`（可建造地砖）
3. 回到 Cocos Creator 编辑器窗口，**等待资源导入完成**（自动生成 `.meta`），然后运行预览

> 选关界面里，这类关卡卡片下方会显示 `📁 文件名`，和内置关卡、编辑器自制关卡区分开。
> 地图文件夹关卡**不受顺序解锁限制**，放入即可直接游玩，方便边改边测。

---

## 坐标系统

整个地图是一张网格，**一律用格子坐标，不是像素**。

| 概念 | 含义 | 范围 |
|------|------|------|
| `col`（列，写作 `x`） | 从左到右 | `0 ~ cols-1` |
| `row`（行，写作 `y`） | 从上到下 | `0 ~ rows-1` |

所以 `path` 里的点是 `{ "x": 列, "y": 行 }`，而 `towerSpots` / `obstacles` 直接写 `row` / `col`。
默认 `cellSize: 140`，即一格 140 像素，`rows: 7, cols: 13` 就是 7 行 13 列。

---

## 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| `name` | 否 | 关卡名。不写则用文件名（自动去掉数字前缀和 `.json`） |
| `rows` / `cols` | 是 | 网格行数 / 列数，默认 7 / 13 |
| `cellSize` | 否 | 单格像素，默认 140，一般不用改 |
| `path` | 是 | 怪物行进路线，**逐格**点列，至少 2 个点 |
| `towerSpots` | 是 | 可建造地砖位置 `[{ "row": 2, "col": 4 }]` |
| `obstacles` | 否 | 可摧毁障碍物，`size: 1`（1×1，200 血）/ `size: 2`（2×2，500 血），`pink: true` 为粉色地砖 |
| `waves` | 是 | 波次配置，见下 |
| `startGold` | 否 | 初始金币，默认 300 |
| `lives` | 否 | 防御点生命，默认 10 |
| `availableTowers` | 否 | 本关可用炮塔，不写则全部可用 |
| `uid` | 否 | 星级记录标识。不写则自动用文件名生成 |

### path 规则（最容易踩的坑）

- **相邻两点必须在同一行或同一列**（正交）。同行/同列的长距离段会自动按直线补全，
  所以 `(0,2) → (3,2)` 这种简写是合法的，等价于 `(0,2) → (1,2) → (2,2) → (3,2)`。
- **不能斜着跳格**：`(3,1) → (4,3)` 是错误的，怪物会直接穿墙飞过去。
  正确写法是逐格绕过去：`(3,1) → (3,2) → (3,3) → (4,3)`。
- 第 1 个点是**出生点**，最后 1 个点是**防御点所在位置**。
- 所有点必须在 `0 ≤ x < cols`、`0 ≤ y < rows` 范围内，越界整个文件会被判为非法并跳过。
- 塔位 / 障碍不要压在路径上，压上了游戏能跑但会很难看 —— 加载时控制台会自动列出（见下方"体检告警"）。

### waves 规则

```json
"waves": [
  {
    "enemies": [
      { "type": "normal", "count": 8, "interval": 1.2, "delay": 0 },
      { "type": "tank",   "count": 2, "interval": 2.5, "delay": 6 }
    ]
  }
]
```

- 一个数组元素 = 一波；`enemies` 里多项会**同时并行**刷出
- `count` 数量 · `interval` 同组内每只间隔秒数 · `delay` 本波开始后延迟几秒才出
- 敌人类型写错会被自动跳过（不会让整关崩掉）；整个 `waves` 为空时会自动补 1 波默认敌人

## 敌人类型（`type` 可用值）

| 值 | 名称 | 血量 | 速度 |
|----|------|------|------|
| `normal` | 普通怪 | 100 | 60 |
| `fast` | 快速怪 | 75 | 120 |
| `tank` | 大型普通怪 | 500 | 40 |
| `big_fast` | 大号快速怪 | 350 | 90 |
| `splitter` | 分裂怪 | 400 | 50 |
| `small_boss` | 小BOSS | 1000 | 40 |
| `boss` | BOSS | 5000 | 30 |

## 炮塔类型（`availableTowers` 可用值）

`emitter`（供能发射器）· `prism`（光电棱镜）· `artillery`（轻型火炮）· `rocket`（火箭塔）
`snow`（雪花塔）· `coagulator`（凝滞器）· `radiation`（辐射能塔）· `tesla`（特斯拉电塔）

## 排序规则

选关界面的关卡顺序是：**地图文件夹（本目录，自动扫描）→ 内置关卡 → 编辑器自制关卡**。
也就是说，`levels` 里的关卡排在最前面，正式关卡的顺序完全由你决定。

文件夹内部按**文件名排序**，用数字前缀控制顺序：`01_`、`02_`、`03_`……
（排序按自然数，所以 `10_` 会排在 `9_` 之后，不是 `1_` 之后）

- 文件名以 `_` 开头的文件**不会被当作关卡**，所以模板 `_template.json` 可以一直留在这里
- 名为 `index` 开头的文件同样跳过
- 不想让示例/测试关卡挤占前面的位置，就把编号调大（`90_`、`99_`），它们会排到同组末尾

## 从地图编辑器导出

游戏内「地图编辑器」点**导出**，下载的 JSON 已经是兼容格式，
把它放进本文件夹即可直接使用；同时该文件也保留了编辑器专用字段（`grid` / `spawn` / `end`），
可以再用编辑器的「导入」按钮无损打开继续改。

---

## 体检告警

每次加载地图文件时会自动做一次"体检"，发现问题只会在**控制台（F12）**输出告警，不会阻止关卡加载：

```
[地图文件夹] 「01_我的地图.json」体检提示:
  - 路径第 2 段 (3,1)→(4,3) 斜线跳格，怪物会直接穿过去
  - 塔位 (row 5, col 4) 压在路径上
```

检查项：路径斜线跳格、塔位压路径、障碍压路径。

---

## 文件没出现在选关里？

按顺序排查：

1. **`.meta` 没生成** —— 最常见。新增 json 后必须切回 Cocos Creator 等它导入完（文件旁出现同名 `.meta`）
2. **JSON 语法错误** —— 检查逗号、引号；控制台会有 `[地图文件夹] 跳过…` 警告
3. **`path` 越界或少于 2 个点** —— 会被判非法跳过
4. **`rows` / `cols` 缺失或不是数字** —— 同样判非法

控制台搜索 `[地图文件夹]` 可以看到每个被跳过文件的原因。
